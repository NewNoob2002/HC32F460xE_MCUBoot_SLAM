Slam-ChargerManager USB

No installation is required. Keep both executables in this directory.

CLI examples:
  hc32-updater.exe info
  hc32-updater.exe install firmware.bin
  hc32-updater.exe wait --version 1.0.0

GUI:
  hc32-updater-gui.exe

Windows binds WinUSB automatically from the device's Microsoft OS 2.0 descriptors.
